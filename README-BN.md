# Creator Studio AI / Creator Layers — Free PWA Starter

এই প্যাকেজটি আপনার আপলোড করা `index.html`-এর ভিত্তিতে তৈরি। মূল ডিজাইন ও টুলের কোড রাখা হয়েছে; PWA চালানোর জন্য `manifest.json`, `sw.js` এবং প্রয়োজনীয় অ্যাপ আইকন যোগ করা হয়েছে।

## ফোল্ডারের ভেতর
- `index.html` — মূল ওয়েব অ্যাপ
- `manifest.json` — Android install/PWA পরিচিতি
- `sw.js` — অ্যাপ শেলের অফলাইন ক্যাশ
- `icons/icon-192.png`, `icons/icon-512.png` — অ্যাপ আইকন

## বিনা খরচে পরীক্ষা করার উপায়
1. ZIP extract করে সব ফাইল একই ফোল্ডার কাঠামোয় রাখুন।
2. শুধু `index.html`-এ ডাবল-ট্যাপ করলে ওয়েবপেজ দেখা যেতে পারে, কিন্তু PWA install/offline সুবিধা সাধারণত চালু হবে না।
3. PWA-এর জন্য HTTPS-এ হোস্ট করতে হবে (বা কম্পিউটারে localhost)। বিনা খরচের static hosting যেমন GitHub Pages ব্যবহার করা যায়।
4. ওয়েবসাইট Android Chrome-এ খুলুন → ব্রাউজারের `⋮` মেনু → `Install app` অথবা `Add to Home screen` (ব্রাউজারের সংস্করণ অনুযায়ী নাম আলাদা হতে পারে)।

## গুরুত্বপূর্ণ সীমাবদ্ধতা
- প্রজেক্ট, নোট ও সেটিংস এখন `localStorage`-এ থাকে; এগুলো ওই ব্রাউজার/ডিভাইসের সঙ্গে যুক্ত, স্বয়ংক্রিয় cloud sync নেই। ব্রাউজারের data clear করলে হারাতে পারে।
- এই প্যাকেজে AI model API যুক্ত করা হয়নি; AI টুলের বাহ্যিক লিংক ও স্থানীয় ইউটিলিটি আলাদা বিষয়।
- অফলাইন অবস্থায় অ্যাপের cached shell ও স্থানীয় কিছু ফিচার চলতে পারে; বাইরের AI ওয়েবসাইট, লিংক ও অনলাইন সুবিধা ইন্টারনেট চাইবে।
- এটি APK নয়; এটি installable web app/PWA প্যাকেজ। APK দরকার হলে পরে আলাদা wrapper/build ধাপ লাগবে।

## টেকনিক্যাল নোট
`index.html`-এ আগে `sw.js` ও `service-worker.js`—দুটি আলাদা worker register করার চেষ্টা ছিল, কিন্তু কোনোটির ফাইলই প্যাকেজে ছিল না। এই সংস্করণে একটিমাত্র `sw.js` registration রাখা হয়েছে এবং HTML-এর শেষে থাকা style block-টি document-এর ভেতরে সরানো হয়েছে।
